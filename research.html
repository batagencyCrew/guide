1. What to research per site

  • Signup vs guest-chat flow – do we need accounts, or can we run guests?
  • Chat transport – websocket / polling / plain HTTP?
  • Skip / next behavior, rate limits, captchas, bans.
  • Whether promotional links can be shared in chat – interested users need a way to reach the relevant social profile or service. If links are unavailable and there is no assigned alternative channel, the site is not suitable for this marketing workflow.
  • Online count – SKIP SITES WITH <~15 online users.
  • Average Visit Time via SimilarWeb (below) – used to calibrate bot count.

2. SimilarWeb – Average Visit Time

  1. Go to similarweb.com. Register / Login if you don't have an account yet.
  2. In the dashboard, search for the site you want statistics for (e.g. camsurf.com).
  3. Open its report, find the Engagement Overview card.
  4. Look for Average Visit Time (avg time per session). That's the number we need.

Example: if it shows 15 min, you test for 15 min acting as a normal user.

3. Bambou's calibration rules

Start around 100 accounts simultaneously. Small sites need fewer, big sites need more – around 100 at once is a good baseline.
Test as a normal user. Launch your bots, then open one normal account yourself and chat for the Average Visit Time you found on SimilarWeb.
Goal is 1 convo per session. In one full session (e.g. 15 min), you should match the AI chatbot about once.
Too few matches → increase accounts. If you test for the full session time and never talk to the AI bot, add more accounts.
Too many matches → reduce accounts. Example Bambou gave: if in 1 min 50 you talked to the AI chatbot 5 times, that's too much – reduce the amount.
Handle bot-to-bot matches. Bots will match each other. Scrape the assigned ID (assigned id=...) where available and skip own IDs. Bambou-side skip may also be added later – for now, just avoid wasting chats on our own bots.
100 bots + 1 normal user → chat for Avg Visit Time → ~1 AI match per session → tune up/down

4. After research

  • If links blocked + no Snapchat workaround → drop the site, pick another.
  • If online count too low → drop it.
  • Otherwise → build prototype fast (see Overview §3).
  • Log findings in the shared sheet so the next dev doesn't repeat the work.
